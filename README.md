# Melsoft Campus Manager

## Project Overview

This project is the Python Essentials 1 Capstone Group Project for Melsoft Academy.

The application is a console-based Campus Manager that allows users to manage:

- Courses
- Students
- Enrolments
- Marks
- Student Transcripts
- Course Reports
- Academy Reports
- Search functionality

The project combines the concepts learned in Project 1 and Project 2 into one application.

## Features

The application includes the following features:

1. Add a course
2. Register a student
3. Enrol a student in a course
4. Record a mark
5. Student transcript
6. Course report
7. Search
8. Withdraw a student from a course
9. Academy report
10. Exit


## How to Run

python campus.py
